## Yêu cầu

- Node.js 18 trở lên (kèm npm)

## Cài đặt

```bash
npm install
```

## Chạy khi phát triển

```bash
npm run dev
```

Mở trình duyệt tại http://localhost:5173

## Build bản chính thức

```bash
npm run build
```

Kết quả nằm trong thư mục `dist/`.

## Xem thử bản build

```bash
npm run preview
```

Mở trình duyệt tại http://localhost:4173
